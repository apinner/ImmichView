A Roku channel for your Immich photo library

Browse your photo timeline, albums, people and places, find photos with smart search (typed or spoken), watch your videos, run slideshows, and, with the companion ImmichView Screensaver app, use your photos as the Roku screensaver. ImmichView connects to an Immich server you run or have access to; it has no service of its own.

Getting started

  1. In the Immich web app, open Account Settings > API Keys and create a key.
  2. Open ImmichView on your Roku and enter your server address (for example https://photos.example.com or http://192.168.1.20:2283) and the API key. The keyboard in the Roku mobile app makes typing the key much easier.
  3. To add more people, press Up to the user button at the top right and choose Add or manage users. With several users, ImmichView asks "Who's watching?" when it opens; each user can set a PIN in Settings (press * on their name).
  4. For the screensaver, add the companion ImmichView Screensaver app from the Roku Channel Store, then pick ImmichView in Roku Settings > Theme > Screensavers. It shows the photos of the user last chosen in ImmichView; choose which photos and what it shows in ImmichView's Settings.

Common questions

Portrait videos play sideways, a video has sound but no picture, or videos won't play on an HD Roku. Roku can't rotate video, can't decode some formats (such as VP9, which some phones record), and HD models can't play HEVC. Roku can't rotate video or play H.264 taller than 1080 pixels (portrait videos). In Immich, open Administration > Settings > Video Transcoding and turn on real-time transcoding with H.264 (and HEVC, for 4K Rokus) at 480p, 720p and 1080p. ImmichView then asks for a version this Roku can play, upright and at the best size it can manage, without changing your stored videos or how they play elsewhere. Keep the usual transcoding (720p, H.264) for the videos real-time transcoding doesn't cover. ImmichView plays Immich's transcodes automatically.

The first search is slow. After your server has been idle, Immich loads its search model on the first search, which can take up to a minute. Later searches are quick.

I forgot a user's PIN. Choose Add user and sign in again with that user's server and API key; this clears their PIN.

"The API key was rejected." The key may have been deleted or may lack permissions. Create a new key in Immich and add it again in ImmichView's Settings.
